# FLM Lab（实验性）

在车机上直接控制左右两只前大灯模块（FLM2，左 `0x43` / 右 `0x44`）。**会发送控制命令，会让灯亮灭**，属于实验性质，风险由使用者自己承担。只读检查请用 FLM Probe。

## 发送的命令

| 用途 | 请求 | 说明 |
| --- | --- | --- |
| 灯光功能 | `2E D6 DC <LV 高> <LV 低> <秒>` | 例如 `0x39` 迎宾灯 1、`0x40` 告别灯 1、`0x33` 日行灯。完整列表见 `lab.js` 的 `FUNCTIONS`。模块回"长度错误"时自动改用 1 字节 LV 再试一次 |
| 单个 LED 通道 | `31 01 A5 4B <通道> <PWM %> <秒>` | 通道 0 表示整只灯的所有通道（包括远光和激光） |
| 停止通道控制 | `31 02 A5 4B` | |
| 诊断会话 | `10 03` / `10 01`，保持期间发 `3E 00` | 只有模块回"当前会话不支持"时才进入扩展会话 |
| 故障码 | `19 02 0C` 读取，`14 FF FF FF` 清除 | |

秒数 = 模块保持多久，`255` 表示一直保持直到停止。这些字节布局按 `FLM02_L/R`（REVISION 2.200）的 SGBD 推出，**首次实车使用前未经验证**。所有请求和模块回复都显示在 Log 页，并追加写入 `data/flm_lab_log.jsonl`。

没有实现的：设定 LED 电流、步进电机、复位、写编码。

## 唯一的限制：车辆移动时不发送

车速超过 3 km/h（`kit/parked.js`）时不发送新命令；正在运行的灯光秀会停止，两只模块会收到停止命令并回到默认会话，交还控制。

## 页面

- **Control**：选择灯光功能并播放（两侧、只左、只右），或者直接控制单个通道（选侧、通道、PWM、保持时间）。
- **Shows**：预设灯光秀（`shows.js`）。经车机发一条命令约 300 ms，所以逐通道的灯光秀每秒最多变化约 3 次；快速效果应写进模块自己的迎宾动画，再用 "Welcome now" 触发。
- **Log**：最近的请求和回复。
- **Faults**：读取 / 清除两只大灯模块的故障码。

底栏按钮（没有 GPU 渲染器时也能用）：Welcome、Play show（当前选中的灯光秀）、Stop all、Next page、Settings。
