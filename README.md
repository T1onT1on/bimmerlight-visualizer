# BimmerLight Visualizer

面向 BMW G20 2020 PreLCI EU 5AZ Laserlight 的浏览器端迎宾灯可视化工具。输入左右 FLM2 的 `Staging1_Data` / `Staging2_Data` 后，工具会解析五条序列，并在按实车轮廓绘制的分层 SVG 大灯上播放。

网页界面名称为 **FLM Light Studio**；本仓库名称为 **BimmerLight Visualizer**。

## 当前功能

- 粘贴完整模板，或粘贴 `0x00` / `00` 格式的裸字节流。
- 在逐字节模式中分别编辑左右 FLM2，每侧提供完整 420 个输入位，并按声明长度分为 CH01–CH06、END 与未使用容量。
- 每个 Channel 显示的是当前声明组数而不是上限；可在末尾按组添加或删除，每组固定包含时间与亮度两个 Byte。
- 人类可读模式会把每个 Channel 自动翻译为“时长（10ms单位）、实际毫秒、目标亮度、累计时间和渐亮/渐暗/保持行为”。
- 可在人类可读模式直接修改控制点，或输入新的时长与亮度添加一组；生成后会同步更新完整十六进制、逐字节视图、曲线和动画。
- 空白字节在预览时按 `00` 处理，支持 Tab 连续输入和批量粘贴分发。
- 校验十六进制字节、序列长度和 Staging 存储上限。
- 绘制 CH01–CH05 的亮度/时间曲线，可按通道隐藏，并单独查看左右大灯；双灯模式中实线表示 Left `[43]`，虚线表示 Right `[44]`。
- 使用全屏曲线编辑器缩放和平移 X 轴，拖动节点或精确输入时间与亮度。
- 在线段上右键新增控制点，在已有节点上右键删除控制点，并自动量化为 10ms / 1% 后重新生成 FLM2 十六进制代码。
- 将生成代码同步到完整模板、四段高级输入和逐字节输入，并支持在浏览器本地保存/加载一份曲线。
- 生成代码始终补满 Staging1 252 Byte 与 Staging2 168 Byte，END 后的剩余容量写为 `00`。
- 播放、暂停、拖动、倍速和循环预览。
- 使用五个彩色 SVG 图层显示每条序列的原始亮度。
- 同时显示 DRL 与近光的合成参考亮度。
- 内置 G20 2020 Original 与 MichaelNRW v15 样例。
- 内置 DoubleSwipe&Flash 样例。
- 保存当前帧 PNG，并在支持 `MediaRecorder` 的浏览器中录制 WebM。
- 载入同一车辆的左右 BimmerCode `.cod` 备份，自动检查 FLM2 左 `0x43`、右 `0x44` 与 VIN。
- 将当前动画重新编码后，仅替换 BimmerCode 备份中的 `0x3009` Staging1 与 `0x300A` Staging2，并下载带同一时间戳的左右备份 ZIP。

## BimmerCode Backup Export

备份导出完全在浏览器本地完成：`.cod` 文件不会上传到服务器。导出前必须同时选择同一辆车的左右 FLM2 备份。工具会保留 VIN、CAFD、ECU identity 以及其他 Coding Block。

> 注意：工具不会重新计算 `0x37F1` 等非 Staging Block。请保留未经修改的原始 BimmerCode 备份；生成文件的最终恢复兼容性必须以 BimmerCode 和车辆实测为准。

## G20 PreLCI Mapping

当前车型配置来自五通道实车闪光测试：

| 序列 | SVG 颜色 | 灯组作用 |
| --- | --- | --- |
| CH01 | 浅蓝 | 四只近光投射模组的主/高亮层 |
| CH02 | 橙色 | 两侧 DRL 的主增亮层 |
| CH03 | 黄色 | 两侧 DRL 的过渡层 |
| CH04 | 深蓝 | 四只近光投射模组的低增益层 |
| CH05 | 紫色 | 四只近光投射模组的高增益层 |

每只大灯内部的两条 DRL 光导同步显示，两只方形近光投射模组也同步显示。当前五条序列不调用 Laser/High Beam；图中的深蓝色代表 CH04，不代表 Laser。

每个彩色图层直接使用原始通道值控制透明度：

```text
SVG opacity = channel brightness / 100
```

因此字节中的渐变时长会直接表现为图层从透明到有色或从有色到透明。页面使用 `assets/G20PreLCIBase.svg` 作为背景与左右灯组的组合画布，左右 CH01–CH05 均保留独立 ID。

页面下方的 DRL/近光合成参考读数采用：

```text
DRL = max(CH02, CH03)
LOW = max(CH01, 0.32 × CH04, CH05)
```

`0.32` 是根据 CH04 明显低于其他近光层的实车观察设置的参考增益，不会改变深蓝色 CH04 图层的原始透明度。

## 左右方向

- 正面视图的画面左侧是车辆右灯，即 FLM2 Right `[44]`。
- 正面视图的画面右侧是车辆左灯，即 FLM2 Left `[43]`。
- 左右灯的几何已在组合 SVG 中定位，网页不反转或重排任何字节。
- 2020 Original 左右数据相同；v15 只有 CH02/CH03 左右不同，从而形成 DRL 左右运动。

## 运行与测试

```bash
npm run serve
```

访问 `http://localhost:4173`。项目没有第三方运行依赖，测试使用 Node.js 内置测试运行器：

```bash
npm test
```

## 精度边界

- 时长、目标百分比和线性插值严格来自输入字节，时间单位为 `Byte × 10ms`。
- 人类可读视图的单组时长范围为 `0–255`，即 `0–2.55s`；更长的过程使用多组连续控制点表达。
- Channel 不使用固定槽位；组数变化会更新两字节长度字段，并移动后续 Channel 与 END 的偏移。
- 曲线编辑器支持移动、新增和删除节点；超过单字节 2.55 秒的线性段会在编码时自动拆分。
- 大灯轮廓来自人工绘制的 G20 PreLCI 5AZ 分层 SVG，不是光学仿真或照片级复刻。
- FLM2 百分比不等于人眼感知亮度，实际灯具仍可能有驱动曲线与硬件响应差异。
- 工具只做离线解析与演示，不连接车辆，也不执行编码写入。
